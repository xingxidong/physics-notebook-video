# 目标音色包

参考课学习在 `reading-practice.json` 记录五类课堂读法，包括英文字母、希腊字母、数学表达式、数学函数和物理公式。每题保存板书符号、完整口播、连读和停顿提示以及课名。遇到分式、根号、上下标、导数点和括号，写清运算作用到哪里。

有原声依据的读法照课堂习惯记录。根据板书或字幕组织的例句标为整理用语。原课时间在回看时用于定位，入库只留课名和读法依据。参考课学习和补库交付文字。

与[常见物理词汇读音卡](../pronunciation-cards/README.md)配合使用。正式制作新课时，结合本课板书选相近句子来写口播。本机的文字索引可从 `runtime-local.json` 中的 `target_voice_reading` 打开。
