# 参数图与动画

直接打开 index.html。三例均可改参数，并保存 parameters.json；再运行：

```sh
python3 SKILL/scripts/animation_examples.py --params parameters.json --output /ABS/OUT/diagrams
```

输出三份可编辑 TikZ、重新计算的 derived.json 和浏览器动画。坐标图和所有公式采用同一组物理参数。TikZ 可用 XeLaTeX 与 `\usetikzlibrary{arrows.meta}` 编译。

- 碰撞：一维正碰、弹性碰撞。输入两质量及碰前速度，计算碰后速度；接触时两球表面相接。箭头长度按同一比例画。口播：“看碰撞前的两个速度箭头。碰后速度由总动量和总动能共同决定；箭头反向表示速度取负。”
- 磁场：速度垂直匀强磁场，忽略重力，B 指向纸内。输入 m、q、B、v，显示圆轨道、切向速度和指向圆心的力；半径数值由 mv/|qB| 算出，画面会适配大小。口播：“速度沿圆弧切线，磁力始终指向圆心。改变电荷符号，转向也随之改变。”
- 薄膜：平行平面界面、两束反射光的几何与相位。输入折射率、入射角、厚度和波长，按折射定律计算膜内角度及 2nd cosθt；反射相位由折射率从低到高的跃迁决定。绿点指示光路先后顺序。口播：“先看直接反射的蓝光路，再看进入薄膜、经下表面反射后出射的绿光路。比较两束光时，还要带上反射相位。”

新课引用这些例子时，把参数、方向、单位和口播一起改。用导出的参数运行脚本，更新 TikZ；勿只修改图上的数值。
