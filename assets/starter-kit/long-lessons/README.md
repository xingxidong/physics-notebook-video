# 两份长课备课模板

- **90 分钟高中课《牛顿运动定律》**。[教案](high-school-90.md) · [课程编排 JSON](high-school-90.json)
- **180 分钟竞赛课《角动量定理、中心力与径向运动》**。[教案](competition-180.md) · [课程编排 JSON](competition-180.json)

Markdown 供老师直接改备课内容。JSON 可作为 `course_outline` 引用，`sample_narration` 存放各段的试讲片段。换自己的教材时，先填写讲义页码和学生已有基础，再调整图、问题、推导和练习。参考[课堂文案改稿](../../../references/classroom-language-editing.md)通读各段如何接续。

每段时长用于备课。完整讲稿写好后，用本课音色正常速度试讲，再把教案交授课人审阅。需要加长时，展开必要的先修内容、推导或变式。学生可以自行暂停记笔记。
