# 五组随包材料

安装后可先重放斜面示例，再按需要打开试音句、备课模板和动画。五组材料均可编辑，随技能一起安装和打包。

| 材料 | 在哪一步用 | 怎么用 |
|---|---|---|
| PDF 到成片的斜面样例 | 首次安装或换电脑时，在第 2 步备课前试跑。首次做习题课也可在第 2 步参考 | 用随包音频跑通从题目、TikZ、口播到落笔和成片的流程。开始新题时参考源文件的组织方式。[斜面样例](incline/README.md) |
| 16 句固定试音材料 | 第 2 步选材与试录，第 4 步送听 | 首次选模型或换音色，用同一批 16 句比较读音、连读、语速和接句，再加上本课普通讲解和关键读式。沿用已确认的配置时，以本课实录为主，按需抽测固定句。送听用准备正式配音的配置录出的实音。[试音说明](voice-trial/README.md) |
| 三种配音配置 | 第 2 步选一种，第 4 步试音确认，第 5 步沿用 | 按实际来源选本地 Qwen、外部接口或已有录音。把参考音频、音色和本课语速填进项目配置。选定后用于本课试音和正式配音。配置变更后重新试音送审。[配置用法](voice-trial/README.md#配音配置与参考声音) |
| 两份长课模板 | 第 2 步编排，第 3 步随四份材料改稿，第 4 步提交成课教案 | 90 分钟高中课和 180 分钟竞赛课分别给出分段方案。按学生基础、讲义页码、重难点、动画、推导和练习重排。用本课完整讲稿和试音估计实际时长。[长课模板](long-lessons/README.md) |
| 三组参数动画 | 第 2 步搭模型，第 4 步送动画预览，第 6 步合成 | 题型相符时，选碰撞、磁场或薄膜案例，换成题目的参数、方向、单位和标签，重算物理量并导出 TikZ。生成本课的动画预览，确认后按实际口播时间同步。[参数动画](animations/README.md) |

```sh
# PHYSICS_SKILL 指向安装目录，Python 环境已安装 assets/requirements.txt，FFmpeg 已在 PATH。
python3 "$PHYSICS_SKILL/scripts/sample_kit.py" render /ABS/EMPTY/demo
# 已配置相应引擎时，也可以加 --renderer motion-canvas 或 --renderer manim。
```

首次重放采用已有音频，不请求语音 API，也不调用文本模型。输出 video.mp4、方格笔记本板书、时间轴和 HTML 预览。替换成自己的题目后，沿用正常教案审阅、术语盘点和成片检查流程。
