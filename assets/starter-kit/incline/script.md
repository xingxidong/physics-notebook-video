# 光滑斜面上的滑块

**read**　这道题看左边的斜面。倾角三十度，表面光滑，斜面固定。小物块从静止释放，沿斜面滑过两米，求末速度。

**observe**　先看它怎样运动。物块沿斜面越来越快。这里的两米，是沿斜面量出来的距离。图上的绿色箭头表示速度方向。

**force**　现在画受力图。重力竖直向下，支持力垂直斜面。沿斜面向下取正方向，把重力分解，沿斜面的分量等于重力乘倾角的正弦。

**newton**　把这个分量写进牛顿第二定律。质量乘重力加速度，再乘倾角的正弦，等于质量乘加速度。等号两边的质量可以约去。

**accel**　所以加速度等于重力加速度乘倾角的正弦。三十度的正弦是二分之一，十乘二分之一，得到五米每二次方秒。

**time**　加速度是常量，初速度又是零。位移等于二分之一加速度乘时间平方，速度等于加速度乘时间。

**eliminate**　把第二个式子平方，得到速度平方等于加速度平方乘时间平方。再用第一个式子消去时间，就有速度平方等于二倍加速度乘位移。

**answer**　代入加速度五、位移二，速度平方等于二十。题目求速率，取正的平方根，答案是二倍根号五米每秒，约四点四七米每秒。

**close**　这道题先用受力求加速度，再用位移求速度。图里沿斜面的方向、式子中的重力分量、以及两米的位移，说的是同一个方向。
