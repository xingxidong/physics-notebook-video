# 本轮新增的课堂读音卡

本轮沿用原有 63 张完整卡的标准，每张保留整词带调拼音、词义及适用条件、可独立朗读的课堂例句、连读提示和易混辨析。例句由制作者另行编写。

合计新增 1,000 张，整库 3,672 张。与已有词卡对照后，把同一概念的别名合并。另一位审阅者按词检查术语读音、例句、物理条件和连读提示，修订后登记终稿。上一批 72 张也已复读，修正了“分度值”的量词和“滞止点”的绕流条件。

换模型或音色时可从这些例句选材，沿用 16 句固定试音。做课时仍逐一检查术语在成片中的实际发音。本次完成的是文字复审。详见[编辑清单](../../../assets/classroom-card-expansions/0.27.6.json)。
