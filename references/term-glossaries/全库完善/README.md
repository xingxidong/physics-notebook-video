# 全库读音卡 · 0.27.3

本轮保留原有 63 张完整卡，补全其余 2,357 张，共 2,420 张。每张包含整词带调拼音、物理词义与使用条件、完整课堂例句、连读与停顿提示、易混读音或概念辨析。

33 节参考课的原笔记仍保存在 references 中。下列 24 批内容由助手重新编写或整理，例句属于补充教学材料。每行链接到原词条所在笔记；详细编辑来源见 [编辑清单](../../../assets/classroom-card-editing.json)。旧卡中的题号片段和占位语由完整词义取代，原资料仍可查阅。

这些卡供配音前选词、试音和成片逐处检查使用。文字整理完成，合成声音仍按具体模型、音色和每一次出现的位置检查。原有 16 句固定试音、字母卡和历史反馈继续参与选材；本轮没有生成音频，也没有添加听音通过记录。

“档位”的拼音已从 dang3 wei4 订正为 dang4 wei4，并同步修改原词表。依据为上海市教委刊载的[《普通话异读词审音表及其说明》](https://edu.sh.gov.cn/yywz_gfbz_gypth/20150712/0015-yywz_1999.html)。存在文白读法差异的词按具体用法处理，未把所有“薄”字一律改成同一种读音。

旧转写词“折反”“挡位”保留作识别提示；正式讲稿采用其卡中注明的“折返”“档位”。
