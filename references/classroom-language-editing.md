# 把物理课讲顺

新授课、习题课和长课都在送审前改一遍教案、完整口播和学生讲义。续做旧课时，连同被改句的上一句、下一句一起读。制作时参考[随包的 Academic Humanizer](../assets/academic-humanizer/GUIDE.md)及其[中文规则](../assets/academic-humanizer/references/chinese.md)。下面的写法用于物理课堂。

## 三份材料各写什么

- **教案**写学生眼前的问题、图上需要先看到的量，以及这段结束时能独立做出的判断。各段接续要有物理理由，例如上一段已知速度，这一段要判断速度每秒变多少。用每一段实际的内容分配课时。
- **口播**从学生此刻能看到的物体、箭头、曲线或刚写完的一项开口。题设、符号、方向、运算和理由按实际落笔顺序说。量名和英文字母在同一口气中读，保留字母、上下标及正负号的区别。有判断需要学生做就把问题写出来，并给出观察或计算的依据。
- **讲义**写完整条件、物理关系和计算，图贴着需要它的步骤。让条件进入正面陈述。正式定义、公式、数据、图号和必要推导都保留。结尾用一道具体判断或本节结果的物理意义，和开头的问题接上。

## 改稿和试讲

1. 通读相邻教学段。圈出只有组织稿子作用的句子、连续相同的段首、含混的“这个量”以及脱离画面的指图词。把这几句改成学生在该处需要的物理关系。常用的“再看”“所以”在有明确承接时照常用。
2. 新旧稿对照条件、单位、公式、图上的方向和求解步骤。出稿前读一遍同段完整口播，检查一听就能知道在对哪项运算。需要停顿时放在完整语意之后，例如两幅图要做比较时。有一句变动就同时读前后两句。
3. 两种课型的 `review-plan` 都生成 `delivery-report.json`，`quality-check` 同时列出讲义行号和口播句编号。制作者先改源文本，再更新教案、板书预览和讲义 PDF。排在一起的几个试讲句，使用本课音色按自然语速试读，观察是否与画面对得上。重新配音后从交付文件复听实际衔接。
4. 学生指出反复出现的措辞时，按[看课反馈](viewer-feedback.md)记下原句、改法和适用情景，下次备课继续读到并检查。

### 课堂中的例子

| 场景 | 容易写成 | 可直接写或说 |
| --- | --- | --- |
| 从第一定律转入第二定律 | 接下来我们将进入下一个知识点。 | 粗糙面上的车减速更快。要比较速度每秒变多少，就看加速度。 |
| 讲有效势的交点 | 这一现象充分说明了这个条件非常重要。 | 看左边的交点。总能量和有效势相等，径向动能为零。轨道上这支切向速度箭头还在。 |
| 交代收绳前后的能量 | 这不意味着机械能一定保持不变。 | 收绳时，拉力沿径向位移做正功，小球的动能增加。 |

## 随包的文字检查

对 Markdown、LaTeX 或纯文本，可在技能目录运行以下命令。改稿时把原文、改稿分别保存，`compare` 会提示公式、数值、引用和限定语的变化，由制作者逐项判断。文字工具的输出是待读的位置。课堂声音的连贯性与自然度用当前音色的真实口播判断。

```sh
python3 assets/academic-humanizer/scripts/check_revision.py audit 教案.md
python3 assets/academic-humanizer/scripts/check_revision.py compare 原讲义.tex 学生讲义.tex
```
