# 学生讲义：编写、配图与排版

适用于习题课、新授课以及新授课中的例题与练习。学生讲义须能独立阅读、记录和复习。教师教案另存课堂提问时机、动画动作和口播节奏。两类材料都按[课堂文案改稿](classroom-language-editing.md)定稿。

## 先确定内容结构

编写正文前，在教案中列出讲义的章节顺序、每节核心问题、应保留的结论、配图及例题作用，再按此顺序展开。内容结构由知识依赖和求解过程决定，不给所有小节套固定数量的环节。

- **新授课**：交代研究对象与现象，建立需要的概念，再展开规律及其依据，安排能说明本课知识的应用。先修内容在首次用到处简明承接。重要定义、定律与结论写全名称、文字表述、公式、适用条件及符号含义，置于学生容易找到的位置。推导解释新关系怎样产生；结尾整理本课知识之间的联系。例题的展开深度服从本节学习目标。
- **习题课**：保留题面及小问编号，先呈现条件与所求对应的图，再按物理过程解释建模、列式、计算与结果。多问共用的关系在后续首次使用处明确承接。每问有完整结论；全题沿一条主推导展开，需要求导、积分或解微分方程时保留必要中间步骤。
- **练习与解答**：每道例题、练习和综合题都有对应题设的图。例题就地讲解；练习保留题目，解答集中编排，题后不附“解答”字样或跳转。集中解答中继续放入计算步骤所需的图。

## TikZ 配图

教学示意图、受力图、电路、光路、几何辅助图与结果图使用 TikZ；函数图可使用基于 TikZ 的 PGFPlots。保留可编辑源码，图的对象、方向、变量、单位和几何关系与正文一致。

每图应承担一个明确的教学任务。把图放在首次据图解释或列式的位置，正文用图号和图中点、路径、方向说明关系怎样进入公式。按推导需要补充分解图、局部图、过程图与结果图。跨页继续使用时可重复必要的小图，并保持符号一致。

用户提供的题图可作为原始资料保存；正式讲义的教学配图按题意重绘为 TikZ。原始照片或实验观测图按其资料用途保留并注明来源，另用 TikZ 补充推导需要的结构示意。检查实际输出的标签、箭头、线条和公式间距。

## LaTeX 排版

正式讲义使用 LaTeX 排版并编译为 PDF，中文默认采用 XeLaTeX 与 `ctex`，配合 `amsmath`、`amssymb`、`tikz`。复用项目中已可正常编译的模板，按实际内容调整。

- 正文中的变量、数学单位和所有公式进入数学环境。用 `aligned`、`align` 或 `gather` 组织多行关系，保持等号、上下标、向量与单位的写法一致。
- 用有限的标题层级区别章节、知识点、例题与小问。少量强调用于定义、定律和核心结论；推导保留正常阅读节奏。标题随其首段正文或图一起排版。
- 配图用 `\input{figures/…}` 引入 TikZ 源，图式编号用 `\label` 与 `\ref` 管理。优先让图与首次使用它的文字同页或相邻，按内容安排浮动位置。
- 把需要对照、相加、相减或联立的式子作为一个阅读单元安排；完整中间关系后再分页。长推导续页时简明带回下一步立刻使用的关系或小图。
- 根据可读性决定字号与页数。先调整结构、换行与图文位置，再决定分页；不以压缩字号、缩小整图或删减必要推导来挤页。

Markdown 可作资料转写或写作草稿。初始化示例中的 `讲义.md` 需要按本规范整理成正式 LaTeX 讲义，再提交教学审阅；已有 Markdown 项目保留其资料，制作新版讲义时补齐 LaTeX 与 TikZ 源码。

## 定稿时重读学生版

推导和图文排好后，单独把讲义从头读一遍。先只看标题、图注和每节最后一段，再连起来读相邻两段。提交审阅前做一轮，交付前拿最终 PDF 再读一轮。后续只改讲义时也执行；改过文字后重编译 PDF，重新打包 LaTeX 和 TikZ 源码。

- 去掉“本题的主线”“本节的主线”“回顾整题”“知识闭环”等写作提纲用语。小标题写物理内容，例如“电压翻倍时的电流”“稳心与重心的位置”。内容已经在前文讲清时，直接删掉复述过程的结尾。
- 让句子的主语落在图中的物体、受力、几何量或刚求出的关系上。相邻段用确实要继续使用的物理量衔接。比如“下面进入稳定性分析”可以写成“图中的浮力作用线从重心右侧通过，产生逆时针力矩”。
- 把适用条件接进当前模型的说明里，用一次正面陈述收住。读到防御性解释时，保留对推导有用的对象、条件和理由。
- 讲义末段只留对学生有用的内容。习题可停在最后一个所求或它的物理含义。新授课可用能独立读懂的定律、条件或具体应用收尾。例如“木块越接近临界宽度，回复力矩越小，横摇越慢”。末段已有这样的内容就自然结束。
- 精简措辞时保留图号、受力取向、变量定义和必要的推导步骤。查词提示只用于找到值得读的地方，是否改写由句子在该题中的作用决定。

## 审阅与交付

1. 新授课检查知识递进、定义和定律的完整性、例题作用及重点位置；习题课检查小问覆盖、图中条件的使用和推导衔接。两类正文都遵循[讲义语言要求](teaching.md#本用户的讲义偏好)，执行上面的定稿复读。
2. 从保留的主文件编译 PDF，完成图式交叉引用；检查编译日志中的错误、未定义引用、缺字和越界。编译失败先修正并说明状态。
3. 将最终 PDF 逐页转为图片并实际查看，检查标题层级、图文距离、公式换行、标签重叠、孤立标题、不合理空白和断页。必要时再看相邻两页的衔接。修改后重编译并复看受影响的页面。
4. 随教案提交学生版 PDF；在 `lesson.json` 显式设置 `handout:"学生讲义.pdf"`。把实际参与编译的主文件、TikZ 源文件、自定义样式和本地插图逐个加入 `review_assets`，使审阅记录覆盖这些文件。正式视频沿用人审教案流程。
5. 交付 `学生讲义.pdf`、`讲义.tex`、`figures/` 中全部被引用的 TikZ 文件及必要的样式、插图；源文件使用相对路径。注明编译方式与实际依赖，使交付目录可重新编译。可用源码压缩包便于下载。

现有 `quality-check` 的 `handout: file-present` 仅确认文件存在。LaTeX 编译、逐页阅读与内容审阅的完成情况需要另记在制作记录中，并如实说明待处理项。
