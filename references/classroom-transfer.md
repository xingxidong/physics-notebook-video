# 一次看课反馈怎样用到别的课

收到反馈，记下完整课堂句、板书上对应的量和作者实际指出的问题。已有同类问题就沿用原编号。作者明确提出的制课要求直接用于适用课程。某个模型的一次试音，保留模型、音色、实际送入文字和原速短样。

## 找出同类问题

从新课的讲稿运行 `course.py feedback-check PROJECT`。打开 `feedback-check.json` 的 `learning_checks`。每个术语标出原句中的字位，每个字母保留原有大小写和下标，每行新写公式标明页、讲解句和书写动作。相同术语出现几次就查几次。与原课单一数字、图号有关的改动仍按原登记的范围处理。

同一问题再发生时，先保留成片原句和相邻接缝，往前比较原始配音、实际送入文本、课程源和时间轴。用 `record` 或 `record-term` 的 `--failed-stage` 记下最早有证据的一环。术语漏认选 `inventory`，稿子本身写错选 `script`，原始录音出错选 `synthesis`，拼接后才出现选 `editing`，板书时间有误选 `board`，导出后才出现选 `export`。尚分不清时用 `unknown` 并写下已有证据。下一课从对应环节先查，最后仍以将要交付的 MP4 为准。

## 用另一节课验证

`python3 scripts/feedback_bank.py trial-audit` 列出各项最新选择、这一版改法的跨课复试以及旧版本的复试。按显示的决定编号用 `retest` 登记。完整例句取自另一节课；同音字提示只写在实际送入文字里，学生看到的字幕和公式用原字。以下命令中的编号、文件、音色和观察文字由制作端按本次实测填写。

```bash
python3 scripts/feedback_bank.py retest --decision-id "$decision_id" \
  --lesson "$lesson_title" --text "$script_sentence" --actual-input "$tts_input" \
  --method audio_probe --outcome "$outcome" --evidence "$observation" \
  --sample "$sentence_wav" --model "$tts_model" --voice-sha256 "$reference_sha256"
```

结果用 `supported`、`problem` 或 `inconclusive`。先写清检查的是一个声调、词内停顿、字母起音，还是一句话的整体连贯。自动测音、制作者实听、作者实听分别用 `audio_probe`、`producer_listen`、`author_listen`；核查物理含义用 `content_review`，核查实测板书时间用 `board_timing`。复试与原改法按内容指纹关联。一次复试保存证据，决定采用或撤回时另用 `decide`。两窗识音相同只能说明该处的声学证据，听整句才能评价它与前后汉字的衔接。

## 三个经过检查的课堂例子

- **分量。** 在“速度有两个分量，切向分量描述小珠沿轨道运动的快慢”里，把配音输入的两个“分量”都试写成“纷亮”。本地 Qwen 在第一处的两个识音窗口均支持 fēn liàng，第二处两个窗口给出不同声调，邻词“切向”也有变化。复录整句后应同时查同词的每一处和邻词。
- **位矢。** 从圆心指向小珠的位矢，其模等于小珠到圆心的距离。把位矢除以它的模，得到该方向的单位矢量。读简称困难时，可以展开读“位置矢量”。在同句测试中，分别寻找“位矢”和“单位矢量”，避免在后一个词中间误抓“位矢”。
- **一步公式怎样讲。** 作者认可第 43 届第二题原版的整体讲法，同时指出字母读音有问题。制作者复看约 5 分 12 秒的切向速度求导，图上的方向和已有公式一直可见，口播先点出腿长、角速度、切向基矢，再说每次求导其余两个因子保留。换到新课，可以让每一项保留它在前式中的来路。同一原则在滑块课的六步推导上做了时间轴复查，并用延迟落笔、两行同时书写作了反例。板书与口播的时间有交集后，仍要看书写的运算是否和当时讲的同一步相符。

这些记录存入技能随行的 `assets/learning/feedback.sqlite3`，声音复试的整句保存在 `assets/learning/samples/`。安装更新会按指纹合并，保留先前选用、试用和撤回的依据。
