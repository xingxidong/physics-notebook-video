# 本用户提供的 edulab 成片参照

用户在本对话中明确赞赏这两条视频的讲解、画面和自然语言，作为后续课程的质量目标。原始文件是手机内播放横屏视频的录屏；制作时以横屏课程内容为参考。

## 实际研究范围

已本地读取两份MP4，提取开场、读题、构造、计算与收束等关键帧；另提取音轨，用本机缓存的Whisper base模型转写。转写仅用于定位口播，数学符号和术语结合画面阅读。未上传到外部转写服务，未复制其音色。

## 范例一：四棱锥与球心

文件标识 `d4fcae5ce7192878dbddbb90331d10bf.mp4`，时长190.3秒。

- 5—35秒：原题卡片常驻，依次框出垂直、平行、长度和所求条件；下方短标签帮助组织题意。
- 约75秒：转到正上方，用底面直角梯形组织球心位置的构造。
- 约115秒：回到立体图，将等距离关系和球面联系起来；右侧笔记同步列出中间关系。
- 约155秒：建立坐标，把向量平移到共同起点，让直线夹角与向量数量积之间的关系可见。
- 末段：用“面面垂直—找球心—求夹角”整理方法，每项对应刚刚做过的图形操作。

可学的口播组织是先给学生一个具体操作，再说这个操作带来什么关系，例如转到俯视图后看底面、平移向量后看夹角。图中对象被明确点名，语句之间有因果推进。

## 范例二：激光测曲率

文件标识 `5ca60250939d5891c79f89541a142226.mp4`，时长185.57秒。

- 开头呈现实验要测什么；随后在原题上逐段突出装置、偏移量和方向角。
- 约75秒：先放大平行玻璃砖的侧移，用入射、折射、出射光线和小角度关系建立第一步公式。
- 中段切到屏幕正视图，把二维光斑位移的方向与竖直分量连起来。
- 约155秒：画弯曲表面、切线、法线、半径与圆心角，将可测量量逐步带入曲率关系。
- 末段把“侧移—折射—竖直分量—圆心角—弧长”串成一条计算主线，再说明实验如何把微小弯曲变为可见的光斑位移。

这与物理竞赛课尤其相配：先拆出一个可以求解的局部，再回到完整装置；不同视图各解决一个空间关系。

## 落到本技能

1. 先把题目条件与所求讲清楚，图形逐步接上条件。
2. 分镜按物理推理组织：画辅助线、分解方向、比较两个量、换到有用视图、再列式。每次动作有教学作用。
3. 图与公式共用符号和参数；讲某条半径或分量时，口播明确点名。颜色在同一课中保持一致。
4. 画面保留当前需要的图和公式；新页承接上一页的对象与状态。完整推导保留在文字讲义和分步板书中。
5. 口播像带学生一起做题：给出操作、指出所得关系、说明下一步理由。采用自然句群合成，在几何转折和新公式后留阅读时间。
6. 笔记本配色与笔迹仍按本用户选择使用。原题高亮、局部放大、辅助线构造和清楚的笔记区可以迁入该风格。

## 当前实现与后续扩展

现有本地引擎已支持真实逐笔汉字与公式、几何图、曲线、关键词落笔、真实音频时间轴和单页缓存。它适合笔记本式推导。

范例中的连续三维视角切换、移动对象和复杂光学演示需要演示层支持；目前这部分尚未由本地笔画引擎通用实现。遇到这类要求，复用 edulab 相应示例和图形模块，或按实际物理解扩展一次后成为可复用组件。扩展后应实际生成与看图，保持物理参数和运动过程一致。

自然声音的具体音色ID从这两条录屏中尚未确认。后端选择参考edulab公开配置，最终以用户对同一段口播的试听选择为准；保留文稿自然程度与音色品质两个独立维度。
