# 课堂表达与节奏

目标是让学生跟着老师看图、判断和计算。音色、句子、停顿与落笔围绕同一个物理动作安排。

## 将讲义改成能讲出口的话

讲义保留完整符号和计算。口播直接说对象、方向与当前运算。第一次用符号时说清它的含义，以后可直接说物理名称或符号。保留因果、限定、负号来源及中间式，按意思安排短句和连贯长句。

每次成稿前按[课堂文案改稿](classroom-language-editing.md)完成两轮修改。

1. **先把逻辑讲清楚。** 每段从上一段刚得到的量、眼前正在变化的对象或这一行要做的运算接起。转折说出物理原因，例如“横向速度保持不变，所以横坐标还要加上这一段飞行的位移”。需要指图时说清颜色、方向、点或线，配合当时可见的画面。条件、正负号、比例和必要的中间步骤逐项对照讲义。
2. **再把句子说顺。** 逐段按课堂速度读一遍。量名和关系词连读，把停顿放在判断讲完、要学生看图或板书快写完的位置。数字按已知量和由哪一步算出的量分组。连续几段都以同一个过渡词开头时，找出各段实际承接的式子或现象。遇到确实需要学生判断的问题，问完给出观察或计算依据。

逐页试讲从声音和画面对照：此刻指哪一个点、哪根线或哪项量？这句补上哪条条件、判断或计算？下一句从哪里接？同一公式已在板书出现时，口播讲取法、项的来历和符号，避免把整屏当成字幕逐字念。在教案里把重点和容易卡住的地方落实为可以看到的动作和可以听到的句子，通读前后段一起调整。口语用词直接，可保留自然的“再看”“好”，接着马上说具体对象。删掉泛泛表态和假装问答，保留真正参与推理的问题。

| 上一版的生硬说法 | 课堂表达 |

| 题目把质量率记作带下标零的质量字母。 | 每秒漏出的质量是 m 零，乘这一小段时间，就是这份水的质量。 |

问题用于引出当下需要判断的关系，回答接着图或式子给出；需要学生看图时才留思考间隔。一个具体难点解释清楚后继续计算。成稿逐句检查：删掉这句话，会少一个物理信息、推理依据或有作用的引导吗？泛泛的流程预告和重复归纳可以删去。

避免把每段都写成相同长度的“小文章”。cue 对应一个完整思考或一个连贯句群，短判断可以单独成段，复杂运算可连续讲。读题、判断方向、链式求导和看结果的节奏由内容决定。

## 配音与停顿

```json
{
  "speech":{"backend":"minimax","delivery_profile":"classroom","trim_edges":true},
  "speech_plan":"speech-plan.json"
}
```

`classroom` 为新课默认模板，普通衔接停顿约 0.15—0.35 秒，关键转折与结论稍长。语速按角色在默认速度附近小幅变化。cue 的显式设置仍优先；旧课未选择该配置时保留原设置。

新课与习题课都先用同一音色各试讲一段普通讲解和一段推导，把听起来最自然的速度用作本课基准。简单代入和常规落笔保持这个节奏。公式提前写完后留在原位，声音继续解释物理意义。需要更长课时，回到教案补齐先修关系或展开难点。全局降语速、拖慢笔划和延长停顿都不能用于凑时长。

需要更长停顿时设置 `pause_reason`：

```json
{"role":"observe","tts":"看红点。它滴出得晚，位置更高。",
 "pause_after":0.9,"pause_reason":"observe_motion"}
```

支持 `phrase`、`read_formula`、`observe_motion`、`think`、`transition`。超过约 1.2 秒的停顿通常应承担明确的教学动作。普通句群结尾不统一加长。`voice-report.json` 区分有记录的教学停顿与其余长静音，并保留实际静音记录。

`trim_edges` 只处理供应商返回音频两端的静音。检测保留首尾余量，并用真实词时间戳保护已说出的内容；句内停顿与语气保留。原始 API 音频缓存保持原样，时间轴和字幕用裁切后同步平移的词时间。没有可靠检测结果时保留原片段。可设 `false` 关闭，或设置 `threshold_db`（默认 -48）、`max_trim_seconds`（默认 1.5）。

保持同一音色。声音的起伏优先来自语义、句子和小幅语速安排。音高仅在实际试听有帮助时使用，默认保持原音高。不给文字加入随机口头禅，也不伪造学生互动、口误或呼吸音。

### 连续讲述组

逐句分别合成很容易把本来连贯的一段推理读成一格一格的短句。需要一口气讲完的相邻 cue 可在 `speech-plan.json` 中标同一个 `speech_group`：

```json
{
  "cues": {
    "compare-force": {"speech_group":"compare-force","role":"explain"},
    "write-relation": {"speech_group":"compare-force","role":"derive"}
  }
}
```

系统将这一组作为一次连续配音，再根据真实词时间在 cue 边界分配板书动作。组内不额外插入机械静音。每组只容纳同一个思路，通常两到四句、约两百字以内。读题、提问、观察、关键转折和总结另起组，让语气在真正的教学动作处转换。用户提供的逐段原始录音不使用该功能。

## 让板书配合讲述

图中的对象在被讲到时突出，运算从口播对应关键词附近开始。参数、投影、微元或方向在本步有作用时再出现；主图和关键关系保持原位。结果在口播结束前写完，随后继续讲解。学生可自行暂停看式或记笔记。重要步骤可以慢下来，简单约分顺着说下去；每步的数学依据照常呈现。

局部放大图从主图的同一几何关系生成，保持方向和比例。动的是物理对象或辅助图，镜头沿用用户已选的固定设置。字幕解释口语，板书保存数学结构。

## 在实际样例中检查

```sh
python3 SKILL/scripts/delivery.py PROJECT
python3 SKILL/scripts/course.py build PROJECT --draft
python3 SKILL/scripts/course.py build PROJECT --video --renderer manim --width 1920
```

`delivery-report.json` 会引用原句，提示套话、连续相同的段首、割开物理量与关系词的停顿、长句和密集报数。结合上下文逐项决定哪里改。改词后复查板书动作与情景动画的关键词锚点，生成实测时间轴时再核对动作先后。

配音后，按 `voice-report.json` 的 `listening_checks` 查看开场、重点推导、结论和异常候选，连同上下文试听（`course.py voice-check PROJECT --listen CUE_ID --context`）。`classroom_delivery` 分开标记句内疑似卡壳、段间空档和文稿问题；关注一口气应读完的术语，以及低电平或短静音之后重复起句。核对有用途的观察或转场与已写的停顿长度。没有可测静音的拖字、错读、吞字、音色突变与不自然重音依靠回听判断。连听前后句，确定要改文本切分、标点、术语读音还是局部语速。先改单段，再重听同一接缝，只重合成改动的段落。实际观看和试听通过后再交付。
