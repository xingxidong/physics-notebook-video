# 课堂表达与节奏

目标是让学生跟着老师看图、判断和计算。音色、句子、停顿与落笔围绕同一个物理动作安排。

## 将讲义改成能讲出口的话

讲义保留完整符号和计算；口播直接说对象、方向与当前运算。第一次用符号时说清它的含义，以后可直接说物理名称或符号。保留因果、限定、负号来源及中间式，按意思安排短句和连贯长句。

| 上一版的生硬说法 | 课堂表达 |
|---|---|
| 把观察时刻固定为题目中的带下标零的时间。 | 现在把画面停在 t 零。这个观察时刻先固定。 |
| 题目把质量率记作带下标零的质量字母。 | 每秒漏出的质量是 m 零，乘这一小段时间，就是这份水的质量。 |
| 两个物理量已经配上了。 | 这份水的质量除以它占的长度，就是线密度。 |
| 接下来我们将分析纵向坐标的变化规律。 | 再看红点。它滴出得晚，落得少，所以位置更高。 |

问题用于引出当下需要判断的关系，回答接着图或式子给出；需要学生看图时才留思考间隔。一个具体难点解释清楚后继续计算。成稿逐句检查：删掉这句话，会少一个物理信息、推理依据或有作用的引导吗？泛泛的流程预告和重复归纳可以删去。

避免把每段都写成相同长度的“小文章”。cue 对应一个完整思考或一个连贯句群，短判断可以单独成段，复杂运算可连续讲。读题、判断方向、链式求导和看结果的节奏由内容决定。

## 配音与停顿

```json
{
  "speech":{"backend":"minimax","delivery_profile":"classroom","trim_edges":true},
  "speech_plan":"speech-plan.json"
}
```

`classroom` 为新课默认模板，普通衔接停顿约 0.15—0.35 秒，关键转折与结论稍长。语速按角色在默认速度附近小幅变化。cue 的显式设置仍优先；旧课未选择该配置时保留原设置。

需要更长停顿时设置 `pause_reason`：

```json
{"role":"observe","tts":"看红点。它滴出得晚，位置更高。",
 "pause_after":0.9,"pause_reason":"observe_motion"}
```

支持 `phrase`、`read_formula`、`observe_motion`、`think`、`transition`。超过约 1.2 秒的停顿通常应承担明确的教学动作。普通句群结尾不统一加长。`voice-report.json` 区分有记录的教学停顿与其余长静音，并保留实际静音记录。

`trim_edges` 只处理供应商返回音频两端的静音。检测保留首尾余量，并用真实词时间戳保护已说出的内容；句内停顿与语气保留。原始 API 音频缓存保持原样，时间轴和字幕用裁切后同步平移的词时间。没有可靠检测结果时保留原片段。可设 `false` 关闭，或设置 `threshold_db`（默认 -48）、`max_trim_seconds`（默认 1.5）。

保持同一音色。声音的起伏优先来自语义、句子和小幅语速安排。音高仅在实际试听有帮助时使用，默认保持原音高。不给文字加入随机口头禅，也不伪造学生互动、口误或呼吸音。

## 让板书配合讲述

图中的对象在被讲到时突出，运算从口播对应关键词附近开始。参数、投影、微元或方向在本步有作用时再出现；主图和关键关系保持原位。结果在口播结束前写完，保留看式时间。重要步骤可以慢下来，简单约分顺着说下去；每步的数学依据照常呈现。

局部放大图从主图的同一几何关系生成，保持方向和比例。动的是物理对象或辅助图，镜头沿用用户已选的固定设置。字幕解释口语，板书保存数学结构。

## 在实际样例中检查

```sh
python3 SKILL/scripts/delivery.py PROJECT
python3 SKILL/scripts/course.py build PROJECT --draft
python3 SKILL/scripts/course.py build PROJECT --video --renderer manim --width 1920
```

文稿检查提示具体的绕行说法、连续相似长段与缺少用途的长停顿。提示需要结合上下文编辑，不能替代物理审阅或试听，也不输出“真人感分数”。

检查 1—3 分钟样例中的真实符号读法、相邻句群衔接、停顿是否恰好给学生看图、落笔与口播是否同步。保留样例的课程源与配音计划，方便修改后只重做有变化的部分。用户未授权等待确认时，样例流程不拦住已经要求的完整成片。
