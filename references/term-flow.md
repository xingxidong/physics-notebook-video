# 物理术语的识别与成片复听

公式试音从[练读例句库](../assets/target-voice/reading-practice.json)直接选相近句子。试音程序按讲稿中出现的量名、公式结构和知识点取样，显示该句记录的课堂、时间和板书式。句中的目标音沿用字母卡及学科词卡，用同一句检查括号、分式、下标、撇号和点号能否随中文自然说出。

## 课堂读音卡

读音卡随技能保存在 `assets/pronunciation-cards/classroom-cards.json`。备课和成片审查都读取这里的整词读音。检查报告给每一个术语附上本课原句。已学习的词用 classroom 标记；本课新词用 this_lesson 标记，制作端确认好可复用的读法与用法后收入持久词表。学习新课时，把词语、逐字带调拼音、实际用法写进该讲的课堂笔记或 `references/term-glossaries/` 的词表。已确定的难词加上“词义与语境、例句、连读、易混”四栏，写一句学生能直接听懂的话。用课堂笔记改写的例句按教学示例保存。只有读音依据的词可先只录拼音；在新课遇到典型用法时补全。同一个字放进不同物理概念中要按词义分开记。每学完一讲运行一次下面的第一条命令，长期词库合并新增内容并保留以前学过的词。多节课同时整理时分文件记录，更新同一份词库。

```sh
python3 scripts/classroom_terms.py --compile
python3 scripts/classroom_terms.py --show 电压差
```

例如“测量电阻两端的电压”中，“测量”读 cè liáng。“测量的物理量是电压”中，第二个“量”读 liàng。电压差读 diàn yā chā，听完整个词才能判断“压”后有没有多一次停顿。持久保存拼音、例句和连读提示即可。删除授课原片后，读音卡仍在。下一节课用自己的最终音轨定位读音，时间指向学生播放的那一句。若作者纠正了词义、易混读法或连读要求，该词以前的实听结果会重新进入待查，其余词按各自记录复用。

## 整课逐词检查

### 自主补充词卡

每次备课由制作端主动查缺补漏，按本课需要补齐物理对象、物理量、定律、几何关系和运算名称。已有词缺少完整例句、词义或连读提示时，优先补全这些字段。已确认的通用用法收入 `references/term-glossaries/`，重新编译后自动进入选材和逐处检查。

助手自行编写的教学例句注明为补充材料；参考课摘录保留各课来源。沿用已确认的读法，有多音、多义分歧时结合原句查词典或学科资料。新增词保留完整中文词形与字典本调；英文字母按字母名与中文整句试读。不同语义分别注明适用用法。

补充后检查拼音音节数与汉字数、同词读法冲突、例句中的物理关系，以及相同词多次出现时能否逐次识别。新卡可供配音选词；实际合成录音仍按对应模型和音色实听。发现错音再追加反馈，保留修订依据。首批示例见[基础力学与电磁学的课堂用语](term-glossaries/自主补充-基础力学与电磁学.md)。


全库词卡已按相同要求完成六项内容，见[逐批词卡与编辑标准](term-glossaries/全库完善/README.md)。扩展新词时继续沿用该标准；字典本调、实际语流和合成音频的审听结果分别记录。

### 制作与复听步骤


1. 先通读整课，包括题面、读图、公式和总结。制作端按学科词表、知识点名称、本课明确命名的概念和历史反馈列出术语。对照题干、图和板书补齐遗漏，例如新材料的名称和本题自定义的量。在 `lesson.json` 的 `speech.physics_terms` 填本课读法，例如 `{"德拜长度":"de2 bai4 chang2 du4"}`。同形词根据本句判断，普通话词义不同的地方用清楚的完整说法。已有读音冲突时先处理词义。
2. 运行 `python3 scripts/course.py feedback-check PROJECT`。查看 `feedback-check.json` 的 `physics_terms` 和 `term_occurrences`，逐词看次数、原句、位置和预期拼音。课中多次出现的术语逐次列出。修改词表或口播后重新识别。若“电压”和“差”横跨两条口播，把完整的“电压差”移到同一句，再安排笔迹同步。自建流水线可直接调用 `term_flow.identify`。
   制作者同时看 `term_candidates`（带原句的候选复合词）与 `terms_needing_readings`（已经识别，但缺读音或来源有分歧的词）。例如讲稿只写“求出德拜长度”时，可以由“长度”找出整词候选；若正文写“这个距离称为德拜长度”，就按整词列出全课出现的位置。候选还需结合题面、图上的标记及语义挑选。确定的词写入本课 `speech.physics_terms` 后重扫；仍待定的正式目标在配音前列出，制作端补齐。一个词在本课选定的读法只适用于本课。
   逐句查看 `term_script_inventory` 的完整原句、已识别词和未覆盖文字，对照题干、图例、板书补上新术语。对每句在项目的 `term-inventory.json` 记录页号、句号、核过的原文指纹、补词和误匹配。制作端负责这一步。改写一句以后，该句会重新进入待盘点清单。示例中偏移量从零起计，课程中别处的“线电流”仍会检查。

   ```json
   {"readings":{"桥接支路":"qiao2 jie1 zhi1 lu4"},"items":[{"page":"p1","cue":"c2","sha256":"复制本句在 term_script_inventory 中的 sha256","extra_terms":["桥接支路"],"exclude":[{"term":"线电流","offset":1,"reason":"此处的绿线电流指绿线中的电流"}]}]}
   ```

   如需为同一句中的第二个“分量”指定日常语义，填写 `speech.term_uses` 条目 `{"page":"p1","cue":"c3","term":"分量","occurrence":2,"reading":"fen4 liang5"}`。使用不同读法时结合该句意思。已确认能迁移到新课的词和连读反馈在本轮写入持久词表并重新编译。

3. 渲染后运行 `python3 scripts/term_flow.py PROJECT --clips`。烧录版用 `--video-file video-captioned.mp4` 指定实际交付件。读 `final-term-flow.json`，从历史反馈词和标出停顿的句子开始，同一句只需听一次，按各处编号逐项登记。时间轴缺字级定位时听整句；有词级定位时还会给出词内静段时长。有独立音节区间时可看到延长的音节。短辅音闭塞、自然重音、词尾的停顿要结合语境判断。听“差”的声调，也听“压”有没有提前收住、“差”有没有另起一口气。
4. 制作者用 `--id 位置编号 --clip` 可单取原句。实听后用 `--id 位置编号 --heard TOKEN 'dian4 ya1 cha1' joined` 登记。TOKEN 来自该处记录。连读填写 `joined`、`broken` 或 `unsure`。读音填写逐字带调拼音或 `unsure`。同句两个“桥接”分别登记。批量使用 `--hearings 实听记录.json`，内容为 `{"位置编号":["该处token","qiao2 jie1","joined"]}`。目标拼音待定的词回到本课词表补齐；按新清单取样复听。
5. 对照原始配音与成片，判断停顿落在词内还是句间。用本课音色重录包含该词的一组相邻句，直到该段的含义讲完整。接缝放在整段边界。保留自然的整句原音，校对口播和正在写的公式。新片再次运行检查，改变的片段和受接缝影响的上下文重新登记。
6. 正式交付前运行 `python3 scripts/course.py quality-check PROJECT --stage final`。自建导出用 `python3 scripts/term_flow.py PROJECT --timeline 时间轴.json --video-file 成片.mp4 --strict`。报告中可见本版成片指纹，每处的读音和连读两项都通过才能完成术语检查。待听、听不清、读错和读断均留在制作端处理。

**保留以后可以回听的好坏样本。** 已截的 WAV 保存在项目的 `review-audio`，数据库保存各位置的实听结果。对同一词选一条确认读断的原句和一条确认自然的原句，记录位置、实际听感和样本路径。可用 `feedback_bank.py compare-audio` 按原速做对照，用已有的 `decide` 将选中的整句样本与模型、音色和反馈关联。作者反馈出现了好坏两种读法但未指定时间时，位置保留待辨。增加新历史词用 `feedback_bank.py record issues --key term-flow-词语 --match 词语 --observed 实际听感`；下次备课时自动列入优先复听。私人录音留在本地项目中。

更新停顿筛查代码后，用 `python3 scripts/term_flow.py 样本目录 --check-samples 样本.json` 重跑本地回归。清单逐项保存 `file`、`sha256`、`term`、词在 WAV 中的起止秒数 `start`、`end` 和声学标签 `pause_candidate`。保留原句，同时用可控的词内插入停顿验证检出、用词外停顿验证定位。这个测试只评估停顿线索。拖音、另起音节、成词的听感由制作者结合原句判定。

## 听完整句话，再决定怎样补录

备课报告的 `speech_context` 保留变量大小写、下标及每次出现的位置。在“测量的量”里分别听 liáng 和 liàng。在“水平分量是 u 乘 q，竖直分量是负 v 乘 q”里按次序听两个乘积，q 有一个 /k/ 起音和一个元音核。沿 z 轴、初速 v₀ 随后面的汉语一起读。连着两个第三声时，记录实际的语流变调。

正常成片终审会生成 `final-speech-context.json`。每一行是一句，包含词或字母的位置、完整口播、该句关联的公式、落笔时刻，以及接缝试听范围。相邻句的末尾和开头都收进原速片段。历史断词同时观察词内静音、持续拖音，以及声音变弱后重新起音的线索。制作端在完整句中判断。

1. 在第一版进入补录前跑一次终审，保存当前时间轴和成片。自建课程可运行 `python3 scripts/speech_context.py PROJECT --video-file 成片.mp4`。同一课程的不同导出使用同一项目目录、实际对应的时间轴和 `review-audio`。
2. 对照原始录音和成片。原声已重复或断词，就用选定音色和原语速补录一个完整意群，最多先比两条；原声流畅而导出后断开，就修句间接缝。随补录重新对齐说到的那一步公式。
3. 用 `python3 scripts/speech_context.py PROJECT --clip 2.3 --video-file 成片.mp4` 导出含相邻句的音画片段。先听整句，听清字母、运算对象和下标，再看同一时刻的板书。在 `--hearings 答卷.json` 按本版 token 登记，如 `{"2.3":{"token":"本片段指纹","checks":{"symbol@4":"ok","join":"ok","board":"ok"}}}`。每处单独标记 ok、wrong 或 unsure。join 包含段间抢话、重复、回音和突兀的音色切换。存在板书时看实际画面后填写 board。第二次运行终审会复用同一段原声和画面的记录。
4. 下次替换音轨或板书，复查清单会列出受影响的原句和相邻接缝。错处归制作端重录，仍有听感分歧的改动按 `author_review` 给作者短片对听。作者无需听完整节课。

### 本地音节和音素复测

对有字词时间的目标，用两个长短不同的声音窗口分别识别。普通话比较具体音节及声调，英语字母比较音素和多余音节。局部定位不清、两个窗口结论不一致、或读法需要结合口吻时，由制作端听整句。详细音素、当前成片指纹和模型指纹保存在本地。整课术语检查可单独运行下面的第一条命令。它读取本次成片术语清单，在每一处取两个上下文；同句有多个相同的词时，逐个匹配各自的原声音节。报告 `final-physics-term-probes.json` 汇总识音支持目标、疑似错读和需要复听的词次。模型判断拼音与制作者实听声调、连读的记录分别保留。

```sh
python scripts/speech_probe.py PROJECT --terms
python scripts/speech_probe.py PROJECT --pending
python scripts/speech_probe.py PROJECT --id 2.3 --target symbol@4
```

使用已配好的本地识音 Python 环境（NumPy、ONNX Runtime、PyTorch、torchaudio、Transformers）。模型目录由 `PHYSICS_NOTEBOOK_PHONEME_MODELS` 指定，默认读取本机缓存中的 `mandarin-syllables` 和 `english-phonemes`。将 `PHYSICS_NOTEBOOK_AUDIO_PYTHON` 指向该环境的 Python，正式终审会逐处运行并复用证据。也可以一次写入本机配置 `~/.local/share/physics-notebook-video/speech-probe.json`，内容为 `{"python":"识音环境的 Python 绝对路径"}`。其余环境沿用整句实听。只有句级对齐的录音保留整句；探针的疑似错音和实听记录分开保存。

### 用真实录音检验下一次升级

保持教师录音在本机。每个样本记下源文件指纹、目标、对齐区间、标签依据；同一节课中好的一次和坏的一次分别保留。作者指出有错但没有确认是哪一次的，保留为待辨样本。语速、自然程度的个人选音只对当时那对试听有效。每轮另留未用于调阈值的新句。作者听判、人工构造的停顿和未知答案分开统计。

```sh
python scripts/speech_blind.py prepare 本地样本.json 本轮目录
python scripts/speech_blind.py screen 本轮目录/clips 本轮目录/模型答卷.json --model-root 本地模型目录
python scripts/speech_blind.py score 本轮目录 本轮目录/模型答卷.json
```

样本清单是数组。每项含 file、sha256、target、task（flow、tone 或 letter）、window（目标在原句中的起止秒）、origin（real 或 control）、label（good、bad 或 unlabeled）和 basis。拼音示例为 liang2，英语目标为 Q /kjuː/。给审听者或模型的是 clips 子目录，匿名 WAV 和问题与私有答案分开。score.json 按真实片段和人为对照分别给出漏报、误报、待定、命中和未标注数；把“待定”保留在分母中。

## 同一句里的不同读音

例如“取速度的分量，这个结论很有分量”。第一个是矢量分量，读 fēnliàng。第二个说结论有分量，读 fènliang。两处保留各自的词义和读法。制作端在 `feedback-check.json` 的 `synthesis_targets` 里可以查原句、偏移、预期拼音、本地配音输入及 MiniMax 的请求词形。本地纯文本配音可用等长同音提示，学生看到的字幕和板书沿用原词。对于本课新增的同句异读，可在对应的 `speech.term_uses` 条目填写已经试读的 `spoken_as`。录好后从实际导出的音轨复听。

收到“刚才把初位移读断了”时，即使原片以后会删除，也可以把这句反馈保存下来。课名和时间有助于本次定位，长期使用依赖技能随行学习库。词义和读法还待确定时只填观察，下次制作会列出待补词。

### 逐句术语盘点版本 2

新课设置 `term_inventory_version:2`。`course.py term-inventory PROJECT` 生成 `term-inventory-draft.json`，包含完整口播、板书、已知词的每次位置，以及文本和语境指纹。

制作者逐句结合图与推导补齐物理对象、量名、关系和运算词。`terms` 保留每次出现的 term、offset；新词填 extra_terms，并在 readings 补带调拼音。误匹配在 exclude 中说明本处词义。填写实际 reviewer 和 evidence，再保存为 `term-inventory.json`。只复制草稿或填写空补词列表仍为待处理。

词典提供候选，无法保证自动发现所有新术语，语义盘点仍需结合课程进行。相同词出现两次要登记两处。口播、板书、题目或符号改变后重看相关语境。盘点后的每次出现进入实际成片的声调与连贯性检查。

换模型或音色使用[固定试音与学习联动](../assets/starter-kit/voice-trial/README.md)：16 句固定材料之外，自动补入随行词卡例句、历史错例和本课难句。每处读音、整词连读分别登记，实际审听结果及音段写回随行包，错误进入下一轮选材。词卡更新后相关句重新待查，音色变更重新录音。本课已盘点的全部术语与字母仍在最终 MP4 逐次检查。其中的公开合成音仅用于比较。

```sh
python3 scripts/feedback_bank.py record-term 初位移 --observed '位和移之间另起了一次音' --reading 'chu1 wei4 yi2' --flow '初位移在一口气里读完' --example '小球的初位移取正。'
python3 scripts/classroom_terms.py --show 初位移
python3 scripts/classroom_terms.py --show q
```

字母卡存有混合课堂句。比如“水平分量是 u 乘 q，竖直分量是负 v 乘 q”，按 u、q、v、q 依次核实。对 v₀ 同时听字母、下标零和后续中文。制作端从本次成片取音，核对公式落笔位置。

同一音色、同一词义的词出现多次时，先逐次核对目标音。至少四处都有可定位的双窗口音节时，再比较词内相邻音节的间隔，将明显偏慢的一处列入整句复听。报告给出位置、词内第几个字和同组的典型间隔。音节起点间距包括前一个音节的发音时长，须听原句区分拖音和停顿。同一个词的多处错音即使完全一致，也保留各自的复听项。制作者回听 `producer_review` 中的整句，同句多个词只播放一次。已经人工确认的自然读法优先作参照，机器匹配另行标记。

盲测结果按实录错例、实录好例和人工注入样例分别计数。输出漏报、误报、待判断和有标签样本数。`speech_blind.py score` 的 `--author-requests` 接收本轮确实交给作者的样本编号列表，按编号去重。没有登记的轮次保留“未知”。

复听中同一个字连续两次偏离目标，可换一句等义的课堂说法再录。例如在弹簧振子的正方向已标清后，可以讲“小球刚松手时，初位移为正”。将新句和原句分别从头读到句末，核实专业词、相邻汉字及板书所指的物理量。机器两次读出目标音时，记录为“识别支持”。准备作为长期音色范例的录音，另保留完整句的实听判断。
