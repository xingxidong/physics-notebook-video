# 知识点结论板书

课程源先列出学生应该记下的定义、定律和结论。每个知识点保留完整文字、适用条件和公式，再安排逐笔书写与讲述。写完即继续讲课，学生可以自行暂停抄录。

牛顿运动定律课应分别写出三条定律的名称与文字表述。第二定律旁保留动量形式和质量不变时的加速度形式。第三定律的文字包括大小、方向、同一直线和作用在不同物体上。讲到惯性、惯性系时，也把定义留下。结论可以在观察后写出，并在随后分析中持续保留。

`kind:"concept"` 的课程使用如下结构。`statement` 是完整表述，`statement_action_ids` 按阅读顺序关联分行的 `type:"text"` 动作，拼接后的文字与正式表述一致。名称可单独关联 `name_action_id`，也可写入表述正文。`formula_action_ids` 关联需要同时保留的公式。`read_seconds` 是可选的最短显示时间，默认 0 秒。旧项目可保留已设定的显示时间。

```json
{
  "kind":"concept",
  "knowledge_points":[{
    "id":"newton-third",
    "name":"牛顿第三定律",
    "page_id":"p06",
    "name_action_id":"law3-name",
    "statement":"相互作用力大小相等、方向相反，沿同一直线，同时存在，分别作用于两个物体。",
    "statement_action_ids":["law3-line1","law3-line2","law3-line3"],
    "formula_action_ids":["third-law"]
  }]
}
```

这些 ID 对应普通板书动作。例如，第一行使用 `{"id":"law3-line1","type":"text","text":"相互作用力大小相等、方向相反，","x":650,"y":180,"size":21,"write_seconds":3}`。名称也是课堂中有用的文字，位置随本页内容安排。

`teaching-check` 检查正式表述能否对应到实际文字和公式动作。构建后，`knowledge-board-report.json` 依据真实音频时间轴记录每个知识点何时写全、当前页何时结束。文字只出现在口播、元数据或讲义中时，需要补上屏幕笔迹。把完整笔迹安排在当前页的讲解中，必要时提前落笔或重新排版。

成片审阅再看完整文字是否易读、与图是否互相遮挡，以及学生能否边听边抄。一个定律讲完，画面上应留下一份完整、能直接整理进笔记的表述。
