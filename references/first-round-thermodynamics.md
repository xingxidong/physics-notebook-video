刘洋讲授。完整播放清单共 17 段原速音轨。本讲用 6033 条播放器字幕、125 张定时板书及重点原声音节整理。课例保留场景、公式和读法。原声抽查与板书转述分别说明。

## 课堂进程

| 课堂环节 | 板书与讲解 | 录课口播 |
| --- | --- | --- |
| 第一定律与典型过程 | 用气体对外做功为正，写热量等于内能增量加对外功。等容时体积不变，等压、等温和准静态绝热过程分别用各自路径计算。 | 先说谁对谁做功，再读等式。定容、定压摩尔热容分别读 C 下标 V 和 C 下标 P。等温功里的自然对数作用于整个末体积与初体积之比。 |
| 循环效率 | 工质回到初态后，净功来自压强体积图的有向面积，净吸热等于总吸热减总放热。课堂也比较了直线过程下方的梯形面积。 | 循环和效率各自连读。先说图线的顺时针方向，再读面积。效率分母用所有吸热段的热量之和。 |
| 热机和制冷机 | 用高温热源、低温热源和工质列热与功的方向，蒸汽机与制冷机的示意图各有三支能量箭头。 | 按图读进去的热、出去的热和功。制冷系数是低温侧取热量除以外界输入功。 |
| 循环中的吸放热分界 | 在压强体积图上，过程线与经过同一状态的绝热线相切时，微元热量为零。三角形例题的斜边按体积从小到大膨胀，过分界体积后从吸热转为放热。 | “相切”的相和切都读第一声。三角形循环的净功从面积读出，取热段由微元热量的正负单独划分。 |
| 卡诺循环 | 两等温支和两绝热支相连。两条绝热线使高温等温膨胀与低温等温压缩各自的大体积除以小体积相等。因而效率为一减低温与高温的绝对温度之比。 | 卡诺的诺读第四声。高温和低温两条支路的体积比依次读，效率分母用高温热源的开尔文温度。 |
| 可逆性、熵和第二定律 | 准静态变化经过连续的近似平衡态。可逆传热的温差趋于零，可逆热量除以绝对温度给出对应熵变。两台热机联动，讨论净热量流向并证明卡诺定理。 | 先说哪台机器反转，再读两台机器的净热量。带撇的伊塔和伊塔属于两台装置。 |
| 隔板和活塞 | 气体向真空自由扩展，不交换热量且外压为零。随后缓慢绝热压缩时，外界做功使内能增加，这一步按准静态绝热关系计算。 | 两步分开讲。吸热、做功、内能三项在第一步均为零。三分之二次方只修饰数二。 |
| 联动活塞 | 区分两个气缸的初态参数、活塞受力和各自的换热条件，用截面积与位移把两侧体积变化联系起来。 | 相同初态温度和体积时，压强比就是物质的量之比。联系两活塞时分别说外力和热源。 |
| 逸出气体 | 最后用固定的一团逸出气体列能量式，初、末态用各自温度和气柱体积，左侧对这团气体做的功用压强乘排出的体积。末尾回到课堂答疑。 | 大写 H 对应初始气柱高度，小写 h 对应留存气柱高度。“大写 H 减小写 h”整体与压强和截面积相乘。 |

## 原声音节和口播整理

- 对 44 个术语位置取两个重叠的原速窗口做本机音节识别，其中 19 处在两次识别里均支持对应目标声调。支持的词包括等容、摩尔热容、正循环、逆循环、热机、制冷机、相切、不可逆、自由膨胀、绝热膨胀和真空。
- 自动字幕中有“卡路循环”这样的转写。卡诺循环和卡诺定理按标题、板书推导及热力学惯用译名写入。音节未对齐的位置以课堂语境确定读法。
- “经过切点时，过程线与绝热线同斜率，这一小段的热量为零。”讲三角形循环时，把“分界体积是 V 零的八分之十五倍”放在分段积分前面。“热机效率的分母是整个循环所有吸热段的热量之和”中的“分母”直接带出整句。
- “把同一团逸出气体从初态跟到末态。先算这团气体的物质的量，再用外界对它做的功求内能增量。”读两个高度时用大写与小写分清。各组合读法依据板书和课堂语境整理。
