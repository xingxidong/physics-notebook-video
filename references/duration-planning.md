# 课堂时长编排

先写学习对象、这节课一定要讲通的问题、所需先修和要留在板书上的结果。习题课按读题、建模、关键推导、结果安排；新授课按每个知识点的引入、讲解、强调、应用检查安排，并同步填写课程编排表。需要额外课时的根本原因写具体，例如“学生刚接触节点电势，需从箭头写出两个带符号的电压差”。

1. 列出教学段。每段粗估会说多少汉字等效口播单位。逗号不计；长公式按实际读法，`V_0^3` 按“维零的三次方”估算。统一语速无法覆盖所有段，推式通常比读题慢。
2. 预估同段板书和动画占用的秒数。这些动作与口播重叠时取较长的一项。确实要单独看一个变化、读完一组公式或自然转场，再另计秒数并注明用途。抄录由学生自停。
3. 报告建议时长、常见范围、逐段依据。如果用户明确给了时长，另外写出目标。预算紧先缩减重复例子、换短演示或拆课。目标更长时，每段新增时间至少对应一个具体收获，例如掌握先修关系、看懂近似的来历、补全关键推导、比较两种物理情况或解一个紧扣本题的变式。
4. 成稿后用无配音时间轴比较计划，逐页查看估算是否能完成讲解和落笔。正式配音后再报实测时长。数字和速度是估算，复杂段以实际画面和试听复核。

先用正常语速和正常落笔速度做估算。教案应列明长讲法增加了哪些内容、每段多用多久、学生将学到什么。禁用全局降低 `speed`、拉长 `write_seconds`、重复念式和延长空白来补足目标。局部放慢只用在需要听清的判断或运算，动作写完后让学生边看结果边听下一句。若有效内容用完后仍有时长差，按自然节奏报告实际预计时长。

分段比较与整课比较一起看。逐段对照口播单位、实际配音时长和落笔片段，尤其检查读题、常规化简和连续书写的节奏。公式难读时拆开说明物理量和运算，笔迹动作密集时拆开排布，让关键图或式在被引用前写完。

作者实际听过上版并反馈语速偏快时，先用目标音色试录完整短段。可用同一段内容提供两档自然语速，记录每档实测的口播单位和秒数。再按选定语速安排本课的讲稿量。全课时长用需要讲清的知识、推导和应用支撑。

在项目内写 `duration-plan.json`，课程源用 `"duration_plan":"duration-plan.json"` 引用。可在写讲稿之前运行 `python3 SKILL/scripts/course.py estimate-duration PROJECT --plan-only`。成稿后省略 `--plan-only`，比较计划与当前稿。旧项目可继续用按现有稿件估算的结果。

```json
{
  "audience": "学过欧姆定律和节点电流守恒的竞赛学生",
  "opening_seconds": 3,
  "sections": [
    {"title":"题图与方向", "mode":"orient", "spoken_chars":170,
     "visual_seconds":34, "observe_seconds":2, "observe_reason":"看清两支电流在节点汇合",
     "reason":"先把支路方向与电压差标清", "pages":["p01"]},
    {"title":"节点方程", "mode":"derive", "spoken_chars":430,
     "visual_seconds":105, "reason":"两条式逐项落笔，再消去共同的桥电流", "pages":["p02"]}
  ]
}
```

`requested_minutes` 只在用户确实指定时填入。`mode` 支持 `orient`（读题引入）、`explain`（概念与判断）、`derive`（推导）、`apply`（应用回收）。每个实际板书页按顺序只归入一个教学段。建议来自各段预期内容和自然语速；教案、`duration-estimate.json` 与 `course-timing-report.json` 可查阅分段数据。后者区分估算稿和已配音实测。

## 将同一道题讲深

例如讲弹簧腿机器人，基本解已经给出离地时刻。学生若还不明白径向方程中为什么出现角速度平方，可以加一小段，先在图上标出旋转的径向单位矢量，再由速度求导，最后带回原题。学生多学会了一个能在别题中使用的步骤。另一个合适的拓展是改变入射条件，让学生借同一条长度曲线判断首次离地时刻。优先补学生会卡住的那一步，所加段落要有板书和推理。

在 `duration_plan.sections` 中给新增教学段附上以下字段，同时填写常规的页号、口播量、并行板书时间和分配依据。

```json
{"extension":{"outcome":"能由速度矢量求出径向加速度","used_in":"列出弹簧腿长度随时间变化的动力学方程"}}
```

有原版配音时，把它的正式 `timeline.json` 单独存到项目内，在时长计划中填 `"reference_timeline":"reference/timeline.json"`。最终检查按相同句段 ID 和相同讲词对照口播，按相同页、句、落笔标识和轨迹对照书写。报告给出命中数和两版秒数。整段重写后，用两版的常规讲解和关键推导实际回听比较。首次制作按学生基础和自然试讲定时。
