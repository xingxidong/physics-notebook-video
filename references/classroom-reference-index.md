# 课堂参考课索引

讲刚体运动、碰撞和复摆时，参照[应老师刷小绿第一期第11次的课堂读音](ying-xiaolv-11.md)。该课记录了实际语境中的术语，以及点名、方向下标、初态下标、撇号和时间导数怎样连着念。成片使用作者选定的教师音色。

讲概率分布、高斯积分、阶乘和含参数的积分时，参照[应老师刷小绿第一期第12次的课堂读音](ying-xiaolv-12.md)。读平均值和平方时，按板书说清先后次序；读积分或偏导时，先指出这一步对哪个变量运算。

讲气体分子碰壁、速率分布、银层沉积和分子势能时，参照[应老师刷小绿第一期第13次的课堂读音](ying-xiaolv-13.md)。Γ 首次出现时说明本题所指的量。平均速率、速率平方的平均值与方均根速率分别按运算顺序念出。

讲小孔喷气、光压、气缸和气体状态图时，参照[应老师刷小绿第一期第14讲的课堂读音](ying-xiaolv-14.md)。同一段并列说明动量小 p 和压强大 P、物质的量 ν 和摩尔质量 μ、速率 v 和速度分量 vₓ。读出孔分子的平均值时，先说分母统计哪些分子，再随图说明法向速度的权重和积分上下限。

讲热力学第一定律、绝热过程、热机和制冷机时，参照[应老师刷小绿第一期第15讲的课堂读音](ying-xiaolv-15.md)。说“对外做功”时先交代做功主体。卡诺循环按图读过程、吸放热和功的方向。热容、绝热指数和效率首次出现时先报量名，再念字母或下标。

讲热力学温标、奥托循环、空调和气体流动时，参照[应老师刷小绿第二期第1讲的课堂读音](ying-xiaolv-16.md)。同一课换题时重新说明贝塔所表示的量。导管题把功率、入口和出口压强念成量名。读气体化学式和工程单位时，随题面说“一摩尔氦气”“一个标准大气压”和“开尔文”。

讲黑体辐射谱、光子能量、过程热容和熵时，参照[应老师刷小绿第二期第2讲的课堂读音](ying-xiaolv-17.md)。用量名区分峰值波长、整个谱的积分和总辐射功率。含积分号的式子口播优先在 tts_parts 写成完整中文，先报积分的变量、范围或闭合路径，再说被积量。

讲多热源换热、热膨胀、表面张力、毛细现象和气液平衡时，参照[应老师刷小绿第二期第3讲的课堂读音](ying-xiaolv-18.md)。先说明热量取正的对象。读曲面压强差时先指两条正交截面，分别报曲率半径。吹泡区别瞬时半径和最终半径，毛细现象区别接触角和管的倾斜角。读温度计的长分式时，先说两个体积相减，再说除以细管横截面积。

讲组合毛细管、水的三相点、静电场梯度和感应电荷时，参照[应老师刷小绿第二期第4讲的课堂读音](ying-xiaolv-19.md)。曲面题里的西格玛先报表面张力系数，带电球面里的西格玛先报电荷面密度。读点乘时把两个运算对象和“点乘”放在同一语音句段。零电势条件随接地符号读，场强为零随轴线上对应的点读。

讲导体球腔、多空腔球壳和电容器换接时，参照[应老师刷小绿第二期第5讲的课堂读音](ying-xiaolv-20.md)。电像法先报实际电荷、像电荷及它们到球心的距离。换接电容器时，先指仍相连的一组极板，再读这组极板的电荷守恒式。读场能量密度先报单位体积内的电场能量。

讲点电荷场能、接地平行板和带空腔的均匀带电球时，参照[应老师刷小绿第二期第6讲的课堂读音](ying-xiaolv-21.md)。读场能积分先说空间区域，读电像序列沿左右两板依次说正负号和距离，读空腔内的场强先说明两个位矢分别从哪个球心量起。电子在分段电场中往返时，把外侧匀变速和中间简谐运动的用时分别读清。

讲电介质界面、电位移以及部分填充的平行板电容器时，参照[应老师刷小绿第二期第7讲的课堂读音](ying-xiaolv-22.md)。读高斯面时先指界面两侧和外法线，再分说自由电荷与极化面电荷。换到等效电路时，先指出哪些区域共用两端电压，哪些区域分担板间电压。

讲无限电阻网、星三角变换和电表改装时，参照[应老师刷小绿第二期第8讲的课堂读音](ying-xiaolv-23.md)。从两个指定端点看进去，再报等效电阻。叠加时给同一支路选定参考方向。读星形支臂或三角形边电阻时先点明对应端点。更换量程时先报公共端和选中的接点，再沿图读表头支路、分流支路和各自电流。

讲电表测量、三端口网络、三极管滞回和电弧稳态时，参照[应老师刷小绿第二期第9讲的课堂读音](ying-xiaolv-24.md)。两次换接由开关位置带出各表读数，做星三角变换前报清三端。读滞回曲线时分开输入上升和下降的方向，判断电弧工作点时先读电流偏大或偏小，再讲调节方向。读电流元的叉乘前，先指出有向长度和单位矢量分别指向哪里。

磁场题配音可参考[应老师刷小绿第二期第10讲的课堂读音](ying-xiaolv-25.md)。先按图读对象、方向和每个分量，再读对应的运算。把“磁力矩、安培环路定理、霍尔效应、完全非弹性碰撞”各读成一个词组；三重积按先做内层叉乘、再做外层叉乘的顺序说。摆线推导中把 x 点和 y 点先读成各轴的速度分量，把欧米伽下标 C 说成回旋角频率。立体角计算中先把大写 R 对应到圆屏半径，把小写 r 对应到投影轨道半径。

配音遇到磁场中的平面刚体运动，按图先讲质心平动、端点绕质心转动各自引起的洛伦兹力，再念合力、力偶矩与两个速度分量。复核“横向分量”“竖直分量”连读时分为第一声，转动惯量的转为第四声。第一次写 $v_{Cx}$ 或 $v_{Cy}$ 要说清质心速度的方向，$\dot\phi$ 与 $\ddot\phi$ 分别按角速度和角加速度读。配速法要先报平衡重力的水平速度，再报剩余的回旋运动。磁矩 $\mu$ 与真空磁导率 $\mu_0$ 同段出现时分别带量名，按坐标方向读势能的偏导。[应老师刷小绿第二期第11讲的课堂读音](ying-xiaolv-26.md)

电磁感应配音可参考[应老师刷小绿第二期第12讲的课堂读音](ying-xiaolv-27.md)。动生电动势先读速度与磁场的叉乘，再读沿杆的点乘；感生电场先指出取哪一圈、磁场覆盖哪一块，再读磁通量的变化率。板书中的大写 R 和小写 r 首次出现时叫出各自的物理量名。遇到变质量和电容电路，用“质量对时间的变化率”“极板电荷量对时间的变化率”分别读两个导数。导体棒进出磁场时，先指参与切割的有效长度，再念电流或机械能变化。

配音遇到超导平面上的镜像磁矩，顺着图先说平行分量和法向分量，分量的“分”和切向的“切”都读第一声，术语内部保持连读。力矩式先报“磁矩叉乘磁感应强度”，再随图报力矩方向；圆环质量、磁矩和真空磁导率各带量名。电磁感应段先报单匝磁通量，再乘匝数读磁通链，匝读第一声。同一页的 $\ell$ 和 $L$ 分别按长度、自感系数读，零电阻线圈先分清外加磁通和自感磁通再读守恒式。[应老师刷小绿第二期第13讲的课堂读音](ying-xiaolv-28.md)

交流电配音时，先报电压和电流谁超前，再跟着相量图念角度。把“容抗、感抗、复振幅、串联谐振”分别连读，相量和相位的“相”都读第四声。整流题先指明哪一对二极管导通，再区分整流平均值、有效值和表盘示数。三相电的相电压和线电压带上各自的两个取点，变压器的原副边电流、自感系数和互感系数先带量名，再按需要读下标。[应老师刷小绿第二期第14讲的课堂读音](ying-xiaolv-29.md)

讲变压器先用图定位电源内阻、原线圈、副线圈和负载，再报电流和匝数的下标。自感系数 $L$ 与互感系数 $M$ 跟着量名读，虚数单位用 $j$。匝数的“匝”念第一声，氖灯的“氖”念第三声，带着阈值和波形说亮灯时段。功率因数接在电压与电流的相位差之后读。绝热变化先按一个振荡周期报极板间距的微小改变量，再念“振荡能量除以固有角频率”。相空间里沿闭合相轨迹报 $p$、$x$ 的量名，再念面积不变。[应老师刷小绿第二期第15讲的课堂读音](ying-xiaolv-30.md)

运动学配音先跟图报坐标轴方向，再读初速度、加速度和速度分量，分量的“分”读第一声，方向下标和初态下标连着变量念。最短时间题先分别报游泳、步行距离，再读各段用时；折射图先指出法线再报入射角和折射角。循环追及和滑轮绳点都要先说明径向是沿哪条线、横向与哪条线垂直。[应老师刷小绿第一期第1讲的课堂读音](ying-xiaolv-01.md)

配音讲力矩时先报取矩点，再随图读各力的作用线和力臂。同一式子中的半角余切与余弦分组念，切读第一声。滚轴题先说接触点在哪个物体上、相对哪个物体滑动，再完整读轴向分量和切向分量，分读第一声。桁架从整体切换到节点时重新报节点号，两个下标按谁对谁的力读，并结合箭头说受拉或受压。立体受力图先指出对应平面，再说在平面内保留的分量。[应老师刷小绿第一期第2讲的课堂读音](ying-xiaolv-02.md)

半球碗的受力图先读对称平面和取矩点，再连读平面内的分量与重力的力臂。转动参考系先报欧米伽所代表的角速度，按板书把速度矢量叉乘地球自转角速度，叉乘读成一组。斜面和直角槽换投影方向时先说研究对象，再说明沿面还是沿法向。在两台阶上的圆柱题里把质心运动定理读全，说明两个物体沿哪条接触法线同速。楔块双下标先念谁相对于谁，再报沿斜面方向与正弦、余弦投影。 [应老师刷小绿第一期第3讲的课堂读音](ying-xiaolv-03.md)

讲功和能时，先报谁做功、哪一种能量在变，再把积分里的微元读清。小车题先说相对小车还是相对地面，把大 M、小 m 和约化质量缪分别介绍。接触与脱离题把木块给球的接触力、杆的轴向力和地面的支持力各自报全，随图读水平分量和切向加速度，分和切均读第一声。正弦余弦跟随角度成组读，长分式先说分母的范围，密度和质量跟完整单位。[应老师刷小绿第一期第4讲的课堂读音](ying-xiaolv-04.md)

竞赛力学配音先报研究对象和参考系，再照箭头读动量或速度分量。角动量式按“位矢叉乘动量”念，位矢和叉乘各自连读，动量的量读第四声。散射题先报碰撞参数和散射角各对应图上的哪一条线，再读入射环带和立体角微元。旋转液体的两种密度带量名和撇号，雪橇、摆球小车及滑块题的速度带相对对象，碰前与碰后分两句读。[应老师刷小绿第一期第5讲的课堂读音](ying-xiaolv-05.md)

碰撞配音先报所问的是碰前、碰后还是法向速度降为零的时刻。二力杆题把两端速度投影到同一杆线，分量的“分”读第一声，带着水平或沿杆方向连读。讲质心运动时先说质心的平动速度，再说端点绕质心的转动速度。天体运动中把位矢、径向单位矢量和位移微元各带量名，点乘和叉乘都连读，随图报运算顺序和保留的分量。椭圆轨道先在图上定位半长轴和半焦距，再念离心率，率读 lü4。[应老师刷小绿第一期第6讲的课堂读音](ying-xiaolv-06.md)

天体配音先说量是到地心、到月心还是沿着矢径，再读径向分量、切向分量和角动量。椭圆图上把半长轴、半短轴、半焦距和半通径各带量名。讲飞船喷气时先说速度相对飞船还是相对月心，初末质量随上下标一起交代。太阳日和恒星日轮换出现时，先报量名，再念大写 T、小写 t 或撇号。轨道积分先说半径是增大还是减小，再按起点、终点的顺序报上下限，英文 arcsin 可按本课统一为反正弦。[应老师刷小绿第一期第7讲的课堂读音](ying-xiaolv-07.md)

简谐振动配音先指出从哪个平衡位置量位移，再把振幅、角频率、初相位结合位移式分别读清。相空间、初相位、同相、反相里的相读第四声，相对坐标、相反方向里的相读第一声。两弹簧夹物块时先报物块的运动方向，再随受力图说摩擦力与该段振动中心。讲耦合的两个物块时按图先报位移的和或差，再念欧米伽的下标和两种简正模式。读复指数先说以 e 为底，再把虚数单位、角频率与时间所在的指数整体念完。[应老师刷小绿第一期第8讲的课堂读音](ying-xiaolv-08.md)

讲振动和波时，先报横轴是时间还是位置，再读同一质点的振动图或同一时刻的波形图。波函数先报传播方向，波数、角频率和初相位各带量名，相位的“相”读第四声。固定端反射按同一位置两份位移相加，驻波的和差化积先读时间因子，再读空间因子。弹簧题先说速度相对哪个物体，刚体题先指出转轴，再念轴承力矩的轴向分量和关于转轴的转动惯量。[应老师刷小绿第一期第9讲的课堂读音](ying-xiaolv-09.md)

质点系受力的两个下标先按谁对谁读。角动量式先念位矢叉乘动量，速度平方展开时念质心速度点乘相对速度，两种运算都连读。讲刚体时先报质心平动，再报绕质心的转动。轮轴的大小半径和角速度各带量名，先找接触点，再读切向分量和法向分量，切与分都读第一声。阐释瞬心时把“速度瞬心”连读，再按图指出速度为零的点，或两条速度垂线的交点。[应老师刷小绿第一期第10讲的课堂读音](ying-xiaolv-10.md)

光学干涉先指两束光从哪里出发、在屏上哪里叠加，再读初相差、光程差和到达相位差。相长的长读 zhǎng，相消的相读 xiāng，衬比度按先差后和念。薄膜反射先指出两个界面、各自的折射率和哪束反射有半波损失，再读膜内往返的光程。光压先说受照面积投影，再读动量的法向和切向分量。康普顿散射先把光子的入射、散射波长和反冲电子分开，接着按能量分量和三个空间动量分量读四维动量。[应老师刷小绿第三期第1讲的课堂读音](ying-xiaolv-31.md)

光学配音先沿图说光从哪种介质走到哪种介质，再指当前界面的法线，说入射角、折射角或反射角。切线、正切、余切的切读第一声，曲率半径、折射率和放大率里的率读 lü4，棱镜的棱读第二声，光纤、纤芯中的纤读第一声，像距的像读第四声。多界面成像把原物、中间像、虚物和最终像逐个带量名，i 撇和 r 撇分别与对应界面的角同读。临界角与偏向角先交代分母的介质或角的参照方向，再报数值。[应老师刷小绿第三期第2个视频的课堂读音](ying-xiaolv-32.md)

原子能级先报初态和末态，再沿箭头读跃迁和光子频率。相对运动中念清约化质量缪、两粒子的质量和共同质心。核物理里读核素时先区分质量数和电荷数，半衰期与衰变常量各带单位。讲洛伦兹变换前先说清事件在哪个参考系，点明带撇坐标和纵向、横向分量。伽马随语境读作伽马射线或洛伦兹因子。[应老师刷小绿第三期第3讲的课堂读音](ying-xiaolv-33.md)
